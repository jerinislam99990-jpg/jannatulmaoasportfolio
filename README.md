# Jannatul Maoa · Portfolio

A personal portfolio for Jannatul Maoa, BBA Finance student at the University of Dhaka, with experience, extracurriculars, certifications, competitions and reports, built around heavy scroll-driven motion.

**Tech:** TanStack Start (React 19), Vite, Tailwind CSS 4, Motion (`motion/react`), Lenis smooth scroll, Netlify Image CDN.

## Run locally
```bash
pnpm install
netlify dev --port 8889   # or: npm run dev
```

## Editing content
All text, photos and links are in `src/content/site.ts`. Photos are in `public/img`, PDFs in `public/docs`.
